# 🖥️ 내 컴퓨터(PC) 무료 실시간 접속·활동 로그 백업 서버 가이드

유료 DB(Supabase 유료 플랜 등)나 유료 호스팅 비용 **0원(100% 무료)** 으로 전 세계 사용자의 **접속 IP, 국가/도시, 로그인 시각, 앱 내 모든 활동**을 실시간 수집하고 내 PC 하드디스크에 자동 백업하는 시스템입니다.

---

## 🚀 1. 가장 쉬운 실행 방법 (원클릭)

1. `pc-log-server` 폴더 안의 **`1_내PC_외부연결_로그서버_시작.bat`** 파일을 더블클릭합니다.
2. 자동으로:
   - 내 PC에서 로컬 로그 서버(`http://localhost:4000`)가 켜집니다.
   - 공유기 포트포워딩이나 회원가입 없이 무료 **Cloudflare HTTPS 보안 터널**(`https://xxxx.trycloudflare.com`)이 생성됩니다.
   - 생성된 보안 주소가 GitHub `log-endpoint` 채널에 자동 등록되어, **`https://indo-word-app.vercel.app`에 접속하는 모든 사용자의 활동 로그가 내 PC로 즉시 전송·백업**됩니다!

---

## 💾 2. 자동 백업 파일 저장 위치

내 컴퓨터의 `pc-log-server/logs/` 폴더에 실시간으로 이중 백업됩니다:
- `pc-log-server/logs/activity_logs.jsonl` : 전체 활동 원본 마스터 데이터베이스 (중복 자동 제거)
- `pc-log-server/logs/daily/YYYY-MM-DD.csv` : **엑셀(Excel)에서 바로 더블클릭해 열 수 있는 날짜별 자동 백업 파일**
- `pc-log-server/logs/archive/` : 로그 비우기 실행 시에도 원본을 안전하게 보관하는 아카이브 폴더

> ⚠️ 개인정보 및 보안 보호를 위해 `pc-log-server/logs/` 폴더는 `.gitignore`에 등록되어 GitHub 공개 저장소에는 절대 업로드되지 않고 오직 내 PC에만 안전하게 보관됩니다.

---

## ☁️ 3. 내 PC를 꺼두었을 때도 24시간 로그를 받고 싶다면? (100% 무료)

1. 앱의 **`중앙 통계` (`/statistics`) -> `서버 연결 설정`** 탭(또는 `pc-log-server/google-apps-script.gs` 파일)에서 구글 스프레드시트 무료 서버 코드를 복사합니다.
2. 내 구글 드라이브의 새 스프레드시트에 붙여넣고 **[웹 앱으로 배포]** 한 뒤 URL을 등록합니다.
3. 이제 **내 컴퓨터가 꺼져 있는 새벽에도 모든 사용자 로그가 내 구글 스프레드시트에 24시간 기록**되며, 나중에 내 PC 서버(`1_내PC_외부연결_로그서버_시작.bat`)를 켜면 꺼져 있던 동안 쌓인 로그까지 내 PC 하드디스크로 자동 다운로드 백업됩니다!
